# Frontend

SvelteKit 3 with Svelte 5 runes, prerendered to static files by `adapter-static` with a `200.html` SPA fallback. It calls the backend from the browser at `PUBLIC_API_URL`; see the [root README](../README.md).

## Run

```sh
cp .env.example .env   # PUBLIC_API_URL=http://localhost:8080
npm ci
npm run dev
```

## Commands

| Command           | What it does                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `npm run dev`     | Dev server                                                                                                                 |
| `npm run build`   | Builds the static site into `build/`                                                                                       |
| `npm run preview` | Serves the production build on port 4173                                                                                   |
| `npm run lint`    | Prettier and ESLint                                                                                                        |
| `npm run format`  | Prettier, writing fixes                                                                                                    |
| `npm run check`   | svelte-check type checking                                                                                                 |
| `npm run e2e`     | Builds with a fake API origin and runs Playwright (Chromium, Firefox, WebKit) with the API mocked, plus axe and CSP checks |

`npm run e2e` reuses a server already running on port 4173, so stop any `npm run preview` first. Install the browsers once with `npx playwright install`.

The Content Security Policy is generated by SvelteKit as a `<meta>` tag (see `vite.config.ts`); `connect-src` allows only this site and the origin of `PUBLIC_API_URL`.
